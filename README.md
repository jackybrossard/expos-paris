# Expos Paris

Expositions en cours des musées parisiens + carnet de visites (date, accompagnant, note, ajout au Calendrier).
Appli web installable (écran d'accueil iPhone), hébergée sur GitHub Pages.

- `index.html` — l'appli
- `expos.json` — la liste des expos (mise à jour chaque semaine)
- `sw.js`, `manifest.webmanifest`, `icon-*.png` — installation et hors ligne
